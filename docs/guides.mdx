## How Zed Cafe is put together

A few words show up in every guide:

- `terminal`: the command line. Open it with `?`, `#`, or `@`. Close it with `esc`.
- `code editor`: where a page's code is edited. Close it with `esc`.
- **Book**: a project. It holds everything your world needs.
- **Page** (or codepage): one item inside a book. Pages have a type: `board`, `object`, `terrain`, `loader`, `palette`, `charset`, or `txt`.
- **Board**: a 60x25 grid of cells. This is a room in your world.
- **Element**: something placed on a board. Terrain fills the floor and walls. Objects sit on top and can run code.
- **Kind**: the name of a page you place, such as `solid` or `lamp`. `#put east lamp` places that kind.
- `inspector`: mouse selection on the board. Turn it on and off with `#gadget`. Also called the `gadget`.
- `makeit scroll`: the `scroll` that opens when you type `@` and a page name. It lists create and edit links.
- `scroll`: a panel of text and clickable lines. Help and creating a page open as a scroll. Two or more lines of what an object says open as a scroll too.
- `ticker`: one line of text at the bottom. A single plain text line from an object shows as a `ticker`.
- `toast`: a short pop-up message, opened with `$toast`.
- **ZSS**: the scripting language for objects, loaders, and the command line. It is close to ZZT-OOP: `@` lines declare stats, `:` lines are labels, and `#` lines are commands.
- **Flag**: a name an object remembers. `#set lit 1` turns it on. `#if lit` tests it.
- **Message**: `lamp:light` tells every lamp to run `:light`. From code, that is `#lamp:light`.
