**Purpose**: Make codepage UI — create object/terrain/board/loader/charset/palette/txt. Guides user through codepage creation with type-specific UI. When multiple books are loaded, a book SELECT picks the create target (last choice persisted in durable `makeitconfig`).

## Dependencies

- `zss/device/api` — vmcli, vmplayermovetoboard
- `zss/device/session` — SOFTWARE
- `zss/feature/writeui` — write
- `zss/feature/zsstextui` — zsstexttape, zsszedlinkline
- `zss/gadget/data/api` — registerhyperlinksharedbridge
- `zss/gadget/data/scrollwritelines` — scrollwritelines
- `zss/mapping/types` — MAYBE, ispresent, isnumber, isstring
- `zss/words/stats` — statformat, stattypestring
- `zss/words/types` — NAME, STAT_TYPE
- `./bookoperations` — memoryensurecodepage, memorylistcodepage, memoryreadcodepage
- `./codepageoperations` — memoryreadcodepagename, memoryreadcodepagetype, memoryreadcodepagetypeasstring
- `./inspectionconfig` — memorycreateinspectionconfig
- `./session` — memoryreadbookbyaddress, memoryreadbooklist, memoryreadfirstbook, memoryreadmainbook

## Key Exports

| Export | Description |
|--------|-------------|
| `memorymakeitcommand(path, data, player)` | Handle a `makeit:*` action invoked from the makeit scroll |
| `memorymakeitscroll(makeit, player)` | Build the makeit scroll (async; loads durable book pick when multi-book) |
| `makeitresolvecreatebook()` | Book used for create (selected id, else main / first) |
| `makeitbookselectindex()` | Index into book list for the SELECT control |
| `makeitsetselectedbookid(bookid)` | Persist create-target book id |
