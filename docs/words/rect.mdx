**Purpose**: Shared absolute board AABB helpers for `DIR.INRECT` and transform `readfilter` region parsing. Coords are inclusive board cells (same layout as former `#erase` / `0,0,5,5` selection paths).

## Exports

| Export | Description |
|--------|-------------|
| `BOARD_RECT` | `{ pt1, pt2 }` normalized min/max corners |
| `normalizerect` | Two corners → inclusive min/max AABB |
| `parserectoneword` | One token `x1,y1,x2,y2` → rect |
| `parserectfromnumbers` | `words[i..]` as `x1 y1 [x2 y2]` → `{ rect, next }` |
| `recttargetpts` | All in-board cells in inclusive AABB |
| `fullboardrect` | Full board default region |
| `ispresentrect` | Type guard |

## Used by

- [`dir.ts`](dir.md) — `readdir` `INRECT` args
- [`zss/memory/boarddirection.ts`](../../memory/boarddirection.ts) — `DIR.INRECT` → `EVAL_DIR.targets`
- [`zss/firmware/transforms.ts`](../../firmware/transforms.ts) — `readfilter` region tokens
