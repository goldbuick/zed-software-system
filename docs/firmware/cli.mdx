## Command Categories

### Messaging

#### #help

**Args:** —

Open reference scroll.

#### #send

**Args:** target, message…

Message to target elements.

#### #shortsend

**Args:** message…

Short-form message (no target keyword).

#### #stat

**Args:** text…

Text in a scroll window.

#### #text

**Args:** text…

Text on element or in sidebar.

#### #hyperlink

**Args:** …

Clickable link in scroll or log.

Example:

```
#text Hello
#send all :touch
#help
```

### Book & Page Management

#### #books

List loaded books; mark opened.

#### #bookopen

Switch opened (live) book by id or name.

#### #bookcreate

Create an empty book without opening it.

#### #bookrename

Rename opened book (operator).

#### #booktrash

Delete book by address (operator).

#### #pages

List pages in all loaded books.

#### #pageopen

Open code editor for page; writes modem init string.

#### #pagetrash

Delete page from opened book (operator).

#### #boards

List boards in all loaded books.

#### #boardopen

Teleport player to board by stat.

#### #search

Search pages and boards across all loaded books.

#### #trash

Show trash menu (books + pages).

Example:

```
#books
#bookopen main
#pages
#pageopen title
#boardopen start
```

### Game State

#### #dev

Halt execution (operator).

#### #share

Share game (operator).

#### #save

Flush (persist); non-operator bookmarks a solo copy.

#### #fork

Fork to new tab (persist); non-operator opens a solo copy.

#### #nuke

Nuke game (operator).

#### #endgame

Logout.

#### #restart

Restart game (operator).

Example:

```
#save
#share
#restart
```

### Export

#### #export

Show export menu.

#### #bookexport

Show book export options.

#### #bookallexport

Download full book JSON.

#### #bookzztexport

Download book as a `.zzt` world (operator).

#### #pageexport

Download page JSON.

#### #itchiopublish

Publish to Itch.io.

Example:

```
#export
#bookallexport
```

### Editing

#### #gadget

#### #findany

#### #perf

### Permissions

#### #access

**Args:** preset

Base preset: lockdown, creative, or open.

#### #permissions

**Args:** —

List player/role and role/commands.

#### #role

**Args:** …

Set player token to a role.

#### #allow

**Args:** …

Add command(s) to a role allowlist.

#### #revoke

**Args:** …

Remove command from role, or revoke all.

#### #ban

**Args:** [playerid]

Ban player, or list players if no id.

#### #unban

**Args:** [playerid]

Example:

```

#permissions

```

### ZNS (namespace redirects)

#### #zns

**Args:** …

Bare `#zns` → menu (login guide, or publish/import when logged in). Login: `#zns <email> <namespace>`, then `#zns <code>`. Subcommands: `login`, `restart`, `publish bytes|book|code`, `import code <key>`, `del`/`delete`. Peer auto-published on multiplayer connect.

Example:

```
#zns
#zns publish book
```
