## Commands

### HTTP

#### #fetch

**Args:** `label` `url` [, method] [args…]

Make HTTP request; `label` is callback target; `method` defaults to `get`.

#### #fetchwith

**Args:** `arg` `label` `url` [, method] [args…]

Same as fetch but passes `arg` to callback.

The `label` is used to route the response to a handler (e.g., a codepage or send target).

Example:

```
#fetch onresponse https://api.example.com/data get
#fetchwith myarg onresponse https://api.example.com/submit post:json x 1 y 2
```

## Supported Methods

Method is optional on `#fetch` / `#fetchwith` and defaults to `get`. Remaining args after the method become request data for methods that take a body.

### get

HTTP GET. Extra args after the URL are ignored by the request.

```
#fetch onresponse https://api.example.com/data get
#fetch onresponse https://api.example.com/data
```

### post:json

HTTP POST with `Content-Type: application/json`. Trailing args are paired as `key value` entries and sent as a JSON object.

```
#fetch onresponse https://api.example.com/submit post:json name alice score 10
#fetchwith myarg onresponse https://api.example.com/submit post:json x 1 y 2
```

That `post:json` body is `{ "name": "alice", "score": 10 }` (or `{ "x": 1, "y": 2 }` for the `#fetchwith` line).
