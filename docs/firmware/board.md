## Command Categories

### Board Creation

#### #build

**Args:** `stat` [, `source`]

Calls [`boardbuild`](../../feature/boardbuild.ts) on the sim. Creates a new TEMP board (optionally clones from source). Exit\* stats set bidirectional board exits. Other standard element stats (`p1`, `group`, …) write the new id on the invoking object; arbitrary names write player flags. Missing source or element fails loud (no create/link).

#### #goto

**Args:** `stat` [, x, y]

Resolves destination (passage match / x,y / start) and calls [`memorymoveplayertoboard`](../../memory/playermanagement.ts). Cross-board `#goto` dither-dissolves to black then in on the local client; same-board position moves and edge exits are unchanged (edge exits keep camera pan).

Cross-board placement commands (`put`/`shoot`/`dupe`/`write`/`shove`/`push` with over/under dirs, etc.) run on the sim against live MEMORY — no worker hydration waits.

Example:

```
#build nextroom
#goto nextroom 10 12
```

### Element Placement

#### #put

**Args:** `dir` `kind`

Place element at direction.

#### #putwith

**Args:** `arg` `dir` `kind`

Place element with arg.

#### #oneof

**Args:** `mark` `dir` `kind`

Place only if no object with `mark` exists.

#### #oneofwith

**Args:** `arg` `mark` `dir` `kind`

Oneof with arg.

#### #shoot

**Args:** `dir` [, kind]

Shoot bullet in direction (default: bullet). Respects maxplayershots. Sets `didshoot` on player.

#### #shootwith

**Args:** `arg` `dir` [, kind]

Shoot with arg.

#### #throwstar

**Args:** `dir`

Shoot star bullet (shorthand for `#shoot <dir> star`).

#### #throwstarwith

**Args:** `arg` `dir`

Shoot star with arg.

Example:

```
#put n red solid
#oneof boss e dragon
#shoot e
#throwstar n
```

### Element Manipulation

#### #duplicate / #dupe

**Args:** `dir` `dupedir`

Duplicate element at dir in dupedir direction.

#### #duplicatewith / #dupewith

**Args:** `arg` `dir` `dupedir`

Duplicate with arg.

#### #shove

**Args:** `dir` `movedir`

Move object at dir by movedir delta.

#### #push

**Args:** `dir` `movedir`

Same as shove but only for pushable objects; a given object succeeds at most once per tick.

#### #transport

**Args:** `target`

First open cell along the shoot ray; an opposite-facing same-kind transporter arms the cell past it; requires approach delta match.

#### #change

**Args:** `[dir]` `group` `into`

Optional spatial **dir** (`rect`, `within`, `at`, …) then **`<group>`** (name, `@group`, or builtins `all` / `terrain` / `object`) and into kind. Into `empty` deletes matches (scoped when dir given). `#change empty <kind>` still fills empty cells (also dir-scoped).

```
#change slime empty
#change terrain empty
#change rect 10 5 20 12 all empty
#change rect 0,0,5,5 terrain empty
#change rect 4 4 12 10 slime gem
#change within 3 i combat gem
```

#### #write

**Args:** `dir` `color` `text…`

Write colored text on board at direction (E/W/N/S).

Example:

```
#duplicate by shootx shooty by 1 0
#shove e n
#push w e
#change slime empty
#change rect 0,0,5,5 all empty
#write e yellow HELLO
```

## Safety

- Player kind cannot be put or shot
- Shooting respects `maxplayershots` and yields after shoot
- Ghost elements bypass collision checks
- Pushable objects are shoved before put when blocking
