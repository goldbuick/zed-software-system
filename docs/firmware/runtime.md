**Purpose**: Defines `RUNTIME_FIRMWARE` — commands for runtime messaging, gadget UI, and scroll/text display. Handles the execution context when codepages run during gameplay.

## Lifecycle

`aftertick` processes the gadget queue for the current element:

- **Single string** — If element exists: empty string clears sidebar; else sets tickertext and tickertime (floating ticker only; no chat/tape)
- **Multiple items** — If player: updates shared sidebar with padded content; else: sets scrolllock, scrollname, scroll for the focused player

## Commands

### Lifecycle

#### #endgame

**Args:** —

Sets health to 0 (triggers game-over flow).

Example:

```
#endgame
```

### UI

#### #help

**Args:** —

Open reference scroll (vmrefscroll).

#### #sessions

**Args:** —

Open the `cpu #sessions` scroll of active multiplayer games for this book. Same command as CLI; hosts set a display name with `#set session <name>`.

#### #send

**Args:** target, message…

Message to target elements.

#### #shortsend

**Args:** message…

Short-form message (no target keyword).

#### #stat

**Args:** text…

Text in a scroll window.

#### #text

**Args:** text…

Text on element or in sidebar.

#### #hyperlink

**Args:** …

Clickable link in scroll or log.

Example:

```
#text Hello
#stat Status line
#send all :touch
#shortsend :ping
#help
#sessions
```

## Design Notes

- Runtime firmware overrides shared behavior for messaging/UI in context
- `aftertick` drives scroll and sidebar updates from the ticker queue
- Writes still pass through `gadgetcheckset` (monitor only; other firmwares own flag names)
