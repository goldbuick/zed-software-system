Glossary

Shared Zed Cafe vocabulary — short definitions, cross-links, and where to read more.

Creator-facing terms for boards, books, #commands, and the terminal.

Jump: B · C · D · E · F · G · H · I · J · K · L · M · O · P · R · S · T · W · Z

B

bgplay

#bgplay plays a short sound-effect pattern on the background synth voices (same notation family as play).

Related: play · command

See: Synth · Notation

board

A playable 60×25 room: terrain, objects, exits, and camera. You walk boards; #boards lists them.

Related: board page · board element · book · exit

See: Your first board

board element

One occupant of a board cell — kind, char, color, collision, cycle, and params like p1–p20. Same idea as element.

Related: kind · chip · collision

board page

A code page that stores a board layout inside a book.

Related: object page · terrain page

book

A container of code pages (boards, objects, terrain, and more). One book is opened; new pages go there. #books lists them.

Related: MEMORY · page

See: Your first ten minutes

C

cafe

The Vite/React app shell at zed.cafe that hosts the Engine and tape UI.

Related: ZED Cafe · ZSS

charset page

A code page of custom character glyphs used when drawing the board.

Related: palette page · CRT

chip

The per-element script runner: compiled ZSS, stats, firmware #commands, and messages between objects.

Related: firmware · label · send

See: Firmware

CLI driver

Where terminal # input runs. Permission checks apply here (unlike loader / runtime).

Related: firmware · tape · command

code page

An editable unit inside a book: board, object, terrain, charset, palette, loader, or txt.

Related: board page · object page

collision

How elements bump: walk, solid, swim, bullet, ghost, and related words used in scripts and the inspector.

Related: kind · DIR

See: Words — collision

color

The 16 foreground colors (plus ON / blink variants) used for chars and #color.

Related: palette page

See: Words — color

command

A hash-prefixed firmware action in the terminal or on a code page — #goto, #play, #put, and the rest.

Related: firmware · CLI driver

See: All commands

creative

An #access preset: players can explore, code, build, and speak. Persist, bridge, moderation, and roles stay restricted.

Related: lockdown · open · operator

CRT

The retro monitor look — post-process effects on the fantasy display.

Related: Engine · gadget

cycle

How often a chip wakes (1–255). Lower cycle means the object runs more often.

Related: chip · halt

D

DIR

Direction vocabulary for movement and targeting: N/S/E/W, SEEK, FLOW, BY, WITHIN, and friends.

Related: collision · command

See: Words — dir

E

element

Something placed on a board: terrain fills the floor and walls; objects sit on top and can run code. In source this is often a board element.

Related: kind · object page · terrain page

Engine

The React root that boots the platform and draws the R3F terminal scene.

Related: cafe · gadget

exit

A board edge link (@exiteast, @exitwest, and the other compass exits). Walking off that edge goes to the named board.

Related: board · board page

See: Your first board

F

fantasy terminal

The product metaphor: boards as worlds, #commands as the OS, scrolls as help, tape as the CLI.

Related: tape · scroll · ZED Cafe

firmware

The registry of #commands and hooks, composed into CLI, loader, and runtime drivers.

Related: command · chip

See: Firmware

flag

A named value on a book, element, or player — script state you #set and #if.

Related: MEMORY · chip

G

gadget

The render / UI projection of the world: layers, scrolls, per-player view. #gadget toggles the inspector overlay.

Related: inspector · layer · tape

H

halt

Dev stop for chip execution (#dev) until cleared.

Related: cycle · operator

hyperlink

A choice line inside a scroll: !label;visible text. Picking it runs that label on the object.

Related: scroll · label · message

See: Your first object

I

inspector

Visual edit mode (#gadget): pick cells, change stats, copy, find-any, remix.

Related: gadget · STAT_TYPE

See: Your first board

itch.io

Publish a build with #itchiopublish (operator).

Related: ZNS · book

J

joincode

Operator starts a multiplayer session and shares a join URL (#joincode).

Related: operator · role

K

kind

The type name of an element — used in #put, #become, collision, and lookup (player, solid, lamp, …).

Related: object page · board element

See: Words — kind

L

label

A named block in object code (:touch, :shot, or your own). Messages and links jump here.

Related: chip · send

See: Your first object

layer

A draw plane in the gadget: tiles, sprites, dither, media, control, and blank.

Related: gadget

loader page

A code page that runs when importing external files (text, JSON, binary, media).

Related: LOADER driver · firmware

See: Loader

LOADER driver

Firmware context for import handlers — no permission checks.

Related: CLI driver · RUNTIME driver

lockdown

An #access preset: tight build/speaker rules; players get no controlled permission groups.

Related: creative · open

M

makeit scroll

The scroll that opens when you type @ plus a page name. It lists create and edit links for that name.

Related: scroll · page · object page

See: Your first object

MEMORY

The live game state root: books, session, loaders, operator. The sim owns it; join tabs project a view.

Related: book · board

See: Memory

message

How objects talk: name:label from the CLI, or #name:label from code, runs that label on matching elements. Built-ins include :touch.

Related: send · label · chip

See: Your first object

O

object page

A code page that defines reusable object behavior bound by kind name.

Related: chip · board element

See: Your first object

open

An #access preset: almost everything allowed for every role; risk still needs #allow or operator.

Related: lockdown · creative

operator

The privileged session player — bypasses permission checks.

Related: role · joincode

P

p1–p20

Generic numeric slots on a board element for custom object state.

Related: flag · chip · stat

page

Everyday name for a code page inside a book — board, object, terrain, loader, palette, charset, or txt.

Related: code page · book

palette page

A code page that remaps board colors.

Related: color · charset page

play

#play schedules melody on the main synth voices. Digits in the string are drums, not octaves — see Notation.

Related: bgplay · command

See: Synth · Notation

player

The login kind / object you control. Starter kits ship an object page named player.

Related: kind · object page · operator

R

role

Assignable identity (admin, mod, player) with permission grants (#role).

Related: operator · lockdown

ROM

Built-in help markdown: refscrolls, editor hints, command docs.

Related: scroll · command

RUNTIME driver

Firmware context when codepage chips run on a board.

Related: CLI driver · chip

S

scroll

An in-world text panel — help, lists, hyperlinks, choices. Not the same as the tape CLI. One plain text line is usually a ticker; two or more open a scroll.

Related: ROM · label · toast

See: Gadget scrolls

send

A message from one element (or the player) to a label or target — the event bus for objects. Players usually say message.

Related: chip · label · message

See: Words — send

starter kit

A ready-made book listed on a fresh session (Quick Start Kit, ZZT Tool Kit, and others). Loading one puts pages into MEMORY so you can play or edit immediately.

Related: book · board

See: Your first ten minutes

stat

An @ field on a page that sets looks or board data — @char, @color, @exiteast, @startx, and friends. Different from a flag, which is runtime #set state.

Related: object page · exit · STAT_TYPE

STAT_TYPE

Inspector / editor categories for stats: board, object, range, hotkey, charedit, and more.

Related: inspector · stat

See: Words — stats

T

tape

The terminal input line and code-editor panel (layout modes top / full / bottom / max).

Related: CLI driver · fantasy terminal

terrain page

A code page of background tile kinds for the board terrain layer.

Related: board page · kind

ticker

One line of text at the bottom of the view. A single plain line from an object usually shows as a ticker; $ticker ... forces that line there.

Related: scroll · toast

See: Your first object

toast

A short pop-up message ($toast ...).

Related: ticker · scroll

See: Your first object

TTS

Text-to-speech (#tts, #ttsengine) via Piper, Supertonic, or Fish.

Related: command · Synth

See: TTS

txt page

A plain-text notes code page (@txt name). No ZSS execution; ZNS can render markdown and $ colors.

Related: ZNS · book

W

words

Shared parsers and enums — color, dir, kind, collision, stats — that firmware and scripts share.

Related: DIR · color · kind

See: Words

Z

ZED Cafe

The product at zed.cafe — fantasy terminal worlds, and the ZSS dialect that extends ZZT-OOP.

Related: cafe · fantasy terminal

ZNS

Zed Name Service — publish and list shareable content (#zns).

Related: book · itch.io

ZSS

Zed Software System — the TypeScript monolith: cafe UI, engine, firmware, and CLI.

Related: firmware · MEMORY

ZZT Museum

Browse classic ZZT worlds with #zztsearch / #zztrandom.

Related: book · command
