title: Files
description: Import, export, and publish worlds in Zed Cafe.
---

| Feature | Audience | Description | Pointer |
|---------|----------|-------------|---------|
| JSON export/import | Both | Book and codepage JSON. `#export` opens the export menus (operator); `#bookallexport` writes the book. | `#bookallexport` |
| #pageexport / #bookexport | Both | Export single page or full book JSON. | `#pageexport` |
| ZZT world import | Creator | Parse classic ZZT .zzt worlds into books. | `zss/feature/docs/parse.md` |
| #zztsearch / #zztrandom | Creator | Search or random ZZT Museum content. | `#zztsearch` |
| BRD / ANSI / CHR | Creator | Board, ANSI art, and charset file parsers. | `zss/feature/parse/` |
| ZIP / OBJ / markdown | Creator | Archive and object format loaders. | `LOADER driver` |
| MIDI import | Creator | Convert MIDI files to play notation. | `zss/feature/parse/docs/midi-import.mdx` |
| itch.io publish | Creator | Package and publish to itch.io platform. | `#itchiopublish` |
| #zns | Creator | ZNS login, list, publish, delete published content. | `#zns` |
