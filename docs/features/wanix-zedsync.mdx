Wanix is a **first-class** product stack integration: the primary path for **complex data** work beyond the tape UI. Live MEMORY exports into `/zedcafe/` so guest WASI/gojs tools, Linux VM helpers, Chromium folder mounts, and remote 9P peers can inspect and mutate allowlisted world JSON. [zedsync](/wanix/zedsync) keeps a peer directory mirrored with that tree.

Full manuals: [`/wanix`](/wanix) · [integration](/wanix/integration) · [zedsync](/wanix/zedsync). System placement: [Product stack](/map#product-stack).

| Feature | Audience | Description | Pointer |

| Wanix integration | Both | Hidden `/wanix.html` iframe runs Wanix; parent owns UI, CLI, and sim export. | [`/wanix/integration`](/wanix/integration) |
