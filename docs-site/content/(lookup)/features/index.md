## [Make a world](/features/boards)

- Boards of terrain and objects, in the ZZT 60 by 25 size
- Build boards, move between them, and place or write elements
- Shoot, throw stars, shove, and push
- Duplicate, change, and pick one of several kinds
- Copy, erase, remix, weave, and rotate regions of a board
- Snapshot a board and revert to it
- Dark boards with per-element light
- Character, color, and background editors
- Inspector for editing an element in place, plus search, batch copy, and a style brush
- In-world scrolls and panels
- Starter kits, including a ZZT-style toolkit
- Drop in files: ZZT and SZT worlds, BRD, ANSI, CHR fonts, ZIP, JSON books, markdown, OBJ, PNG, JPEG, GIF, WEBP, and MIDI
- Export a page, a book, or a ZZT world, and pack a zip for itch.io
- Search the Museum of ZZT, or open a random world
- Publish and manage worlds on ZNS
- Attach a folder on disk and edit the live book as JSON

## [Script it](/features/elements)

- ZSS, a scripting language in the spirit of ZZT-OOP
- Pages for objects, terrain, boards, loaders, charsets, palettes, and text
- Tape editor with syntax color, command autocomplete, and command hints
- More than one person can edit the same page
- Move, walk, idle, become, bind, and morph
- Flags, arrays, and running another object's code
- Messages between elements, scrolls, sidebar text, links, toasts, and tickers
- Lock a script, set its speed, and turn labels off or back on
- Fetch a URL into the running world

## [Play](/features/display)

- Keyboard, gamepad, and touch controls
- Move, shoot, confirm, and cancel
- Health, and an end-of-game
- Prompts that ask the player for input
- Layered display: tiles, sprites, dither, pictures, and video
- Zoom, CRT, scanlines, and a low-resolution look
- Screenshots

## [Sound and speech](/features/synth)

- Foreground and background music from written notes
- Four play voices, plus a separate background voice
- Waves, FM, fat and AM stacks, noise, drums, and instruments such as string, piano, flute, and brass
- Echo, reverb, distort, crush, filter, vibrato, and wah, including per-voice sends
- Record the synth to an MP3
- Text-to-speech with Piper, Supertonic, or Fish, plus a speak queue and voice choice
- Speech-to-text from the microphone
- Separate volumes for the mix, music, background, board video, and speech

## [Together](/features/multiplayer)

- Host a session and join it with a code, another browser tab, or a share link and QR code
- The host runs the world; joined players play on that world
- A joined player can fork a personal copy
- In-game chat
- Bridges for Twitch, RSS, Mastodon, and Bluesky
- Broadcast the session out
- Roles, bans, and permission groups for building, coding, exploring, speaking, saving, and moderation
- An admin screen for the session
- A peer-to-peer terminal for sharing the command line

## [Keep it](/features/session)

- Save the session in the browser
- List, open, create, rename, search, and trash books and pages
- Login and a player identity
- Wipe the session, or restart it

## [The terminal](/features/help)

- The command line is the front door: help, books, pages, and boards all start there
- Scrolls with hotkeys and clickable lines
- The same world can run in a terminal, with no board window, through the headless CLI
