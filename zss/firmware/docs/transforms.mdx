## Commands

### Board transforms

#### #snapshot

**Args:** —

Calls [`boardsnapshot`](../../feature/boardsnapshot.ts) on the sim — creates MAIN `zss_snapshot_*` codepage and copies current board.

#### #revert

**Args:** —

Calls [`boardrevert`](../../feature/boardsnapshot.ts) on the sim — restores current board from snapshot codepage.

#### #erase

**Args:** [filter…]

Erase matching elements; filter **`<group>`** (optional color) or builtins `all`/`terrain`/`object`.

#### #weave

**Args:** `dir` [filter…]

Weave board; filter **`<group>`** or builtins.

#### #pivot

**Args:** `degrees` [filter…]

Rotate; filter **`<group>`** or builtins. Optional shear keyword (`taper_floor`, `taper_ceil`, `taper_trunc`, `mishin_floor`, `mishin_ceil`, `shear_soft`, `shear_hard`) then region / targetset.

#### #copy

**Args:** `stat` [filter…]

Copy region; filter **`<group>`** or builtins.

#### #remix

**Args:** `stat` `pattersize` `mirror` [filter…]

Remix; custom filter is group/kind name via `@group` or display name.

Example:

```
#snapshot
#erase terrain
#weave n object
#pivot 90 all
#copy otherboard
#remix otherboard 4 1
#revert
```

## Filter Grammar

`readfilter` parses optional filter args after command-specific args (`#erase` takes only the filter; `#pivot` / `#weave` / `#copy` / `#remix` parse it after their own args):

- **targetset** — default `all`
- **region** — `x1 y1` (single cell) or `x1 y1 x2 y2` (inclusive corners)
- **region (one token)** — `x1,y1,x2,y2` — same layout as `ptstoarea` / batch selection paths; required so values like `0,0,5,5` are not misread as `parseFloat` → `0` with missing follow-up numbers

Filter controls which elements are affected:

- Built-ins: `all`, `terrain`, `object` (and `self` / `others` where applicable)
- **`<group>`** — optional color prefix; matches `@group` **or** element display name via `memoryreadgroup` / `memorylistelement({ group, self })`

### Builtin targetsets

```
#erase
#erase all
#erase terrain
#erase object
#pivot 90 terrain
#weave n object
```

### Group / display name

```
#erase slime
#erase red key
#pivot 90 wall
#weave e doors
#copy otherboard slime
```

### Region as four numbers

```
#erase 10 5 20 12
#erase terrain 0 0 59 24
#pivot 90 object 5 5 15 15
#weave n all 2 2 8 8
```

### Region as one comma token

Needed when the rect is a single word (selection / paste paths):

```
#erase 0,0,5,5
#erase object 10,5,20,12
#pivot 90 slime 0,0,30,20
#copy otherboard all 0,0,59,24
```

### Combined targetset + region

Order can mix; both are applied:

```
#erase slime 4 4 12 10
#erase 4 4 12 10 slime
#remix otherboard 4 1 terrain 0,0,20,12
```

## pickcodepage

Helper that searches books for a codepage of given type and stat/address (`memorypickcodepage(memoryreadbooklist(), type, stat)`). Used to resolve `stat` in copy/remix to a source board.

## Implementation Notes

- `snapshot` / `revert` call feature modules directly on the sim (same pattern as `#build` → `boardbuild`)
- `weave` uses `READ_CONTEXT.element` position for delta
- `pivot` uses degrees converted to radians
- All commands require READ_CONTEXT.book and READ_CONTEXT.board
