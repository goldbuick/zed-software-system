## Command Categories

### Text-to-Speech

#### #ttsengine

**Args:** [ `engine` [, `config` ] ]

List engines (no args) or set TTS engine and optional config.

#### #tts

**Args:** [voice] [, phrase]

Speak phrase with voice; no args = clear queue; voice only = info.

#### #ttsqueue

**Args:** `voice`, `phrase`

Queue TTS text.

#### #ttsvol

**Args:** `volume`

Set TTS volume.

Example:

```
#ttsengine
#tts default hello
#ttsqueue default next line
#ttsvol 0.8
```

### Playback

#### #play

**Args:** [buffer]

Play audio buffer (can reference chip variable).

#### #bgplay

**Args:** [buffer]

Play background audio.

#### #vol

**Args:** `volume`

Set main volume (scales all audio).

#### #playvol

**Args:** `volume`

Set foreground play volume.

#### #bgvol

**Args:** `volume`

Set background playback volume.

#### #mediavol

**Args:** `volume`

Set board TV volume.

Example:

```
#play ceg
#bgplay #xyzzy
#vol 0.7
#mediavol 0.5
```

### Synthesis

#### #synth

**Args:** [voice config…]

Configure all 4 play voices; no args = restart synth.

#### #synth1 … #synth4

**Args:** [config…]

Configure individual play voices.

#### #synth5

**Args:** [config…]

Configure background synth voices (4–8).

#### #synthrecord

**Args:** [filename]

Record synth output.

#### #synthflush

**Args:** —

Flush synth buffer.

Example:

```
#synth
#synth1 buzz
#synth5 pad
#synthrecord take1
#synthflush
```

### Effects (multi-voice)

#### #echo

Echo on voices 0–1.

#### #fcrush

Bitcrush (fc) on voices 0–1.

#### #autofilter

Autofilter on voices 0–1.

#### #reverb

Reverb on voices 0–1.

#### #distort

Distortion on voices 0–1.

#### #vibrato

Vibrato on voices 0–1.

#### #autowah

Autowah on voices 0–1.

Example:

```
#echo 0.3 0.2
#reverb 0.4
#fcrush 4
```

### Per-voice effects

#### #echo1 … #echo4

Echo on voice pair / bgplay / TTS (`1`–`3` play/bgplay, `4` TTS).

#### #fcrush1 … #fcrush4

Bitcrush on voice pair / bgplay / TTS.

#### #autofilter1 … #autofilter4

Autofilter on voice pair / bgplay / TTS.

#### #reverb1 … #reverb4

Reverb on voice pair / bgplay / TTS.

#### #distort1 … #distort4

Distortion on voice pair / bgplay / TTS.

#### #vibrato1 … #vibrato4

Vibrato on voice pair / bgplay / TTS.

#### #autowah1 … #autowah4

Autowah on voice pair / bgplay / TTS.

Example:

```
#echo1 0.2 0.1
#reverb4 0.5
#fcrush2 3
```
