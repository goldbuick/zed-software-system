**Purpose**: Defines `ELEMENT_FIRMWARE` — commands and hooks for element stats, movement, lifecycle, code execution, and player input. Provides the core vocabulary for object behavior.

## Flags / stats

Names used with `#set`, `#clear`, expressions, and `is`. **Access** is whether the element hook persists a write (`Read/write`) or ignores / does not own the write (`Read-only`).

Color, collision, category, and dir **keywords** also resolve through a const map for expressions — those are not stored stats.

### Input

Player chips only. Values come from the input queue (`inputmove` / `inputshoot` may list up to two dirs for diagonals; FPV remaps dirs).

| Name | Access | Notes |
|------|--------|-------|
| `inputmove`, `inputshoot` | Read-only | Direction lists from move / shoot |
| `inputok`, `inputcancel`, `inputmenu` | Read-only | Face buttons / menu |
| `inputa`, `inputb`, `inputx`, `inputy` | Read-only | Extra face buttons |
| `inputl1`, `inputl2`, `inputr1`, `inputr2` | Read-only | Shoulder buttons |
| `inputalt`, `inputctrl`, `inputshift` | Read-only | Modifiers |

### Player flags

Open read/write bag on the focused player (`BOOK_FLAGS`). Any name that is not a board/element/env/input hit falls through here. Examples:

| Name | Access | Notes |
|------|--------|-------|
| `health` | Read/write | Player health; ≤ 0 ends the program (see Lifecycle) |
| `user`, `voice` | Read/write | Sticky on the local tab (`register:stickyuser` / `register:stickyvoice`) |
| `camera`, `graphics` | Read/write | Display prefs (player flags; no board fallback on get) |
| `facing` | Read/write | Degrees 0–359; get falls back to board facing if unset |

If a name matches an object id key on the current board, **get** returns that id string (alias). That path is read-only.

## Lifecycle

`aftertick` on element firmware:

- **Walk** — If the element has `stepx` / `stepy`, move it; on blocked move send `:thud`
- **Health** — If player and `health` ≤ 0: end of program and logout

## Commands

### State

#### #set

**Args:** `name` `value`

Set stat (default value 1). Value may be an expr, e.g. `set name pget <dir> <attr>`.

#### #clear

**Args:** stat…

Set listed stats to 0.

#### #pset

**Args:** `<dir>` `attr` `value`

Write remote attr (`step`/`shoot` ← dir → axes; `light <n> [dir]` → lightsteps + cone).

#### #cycle

**Args:** `value`

Set cycle (1–255).

Example:

```
#set health 100
#clear didfail
#pset n step e
#cycle 4
```

### Movement

#### #go

**Args:** `dir`

Move element to dest; yield; return 0 if moved, 1 if blocked.

#### #walk

**Args:** `dir` `[name1 name2]`

Set stepx/stepy, or capture deltas into names.

#### #idle

**Args:** —

Yield until next tick.

Example:

```
#go n
#if didfail
#walk e
#idle
```

### Transformation

#### #become

**Args:** `kind`

Transform into kind (preserve color), delete self, create new, endofprogram.

#### #morph

**Args:** `kind`

Drop code/kinddata, set kind (object source; object or terrain target); halt chip.

#### #bind

**Args:** `name`

Copy kind and instance code from named element; halt chip.

#### #char

**Args:** [dir] `value`

Set char at dir or self.

#### #color

**Args:** [dir] `color`

Set color at dir or self.

Example:

```
#char 2
#color red
#morph lion
#become key
```

### Lifecycle

#### #die

**Args:** —

Safely delete element; if item, yoink player to position; else endofprogram.

#### #end

**Args:** [result]

Set arg if result, endofprogram.

#### #lock

**Args:** —

Lock chip against external messages.

#### #unlock

**Args:** —

Unlock chip against messages from others.

#### #restore

**Args:** `id`

Restore all labels of given name.

#### #zap

**Args:** `id`

Zap (de-activate) first label of given name.

Example:

```
#lock
#zap touch
#restore touch
#unlock
#end
```

### Code Execution

#### #run

**Args:** `func`

Run object codepage of given name.

#### #runwith

**Args:** `arg` `func`

Set arg, run codepage.

#### #load

**Args:** `dir` [, action]

Load code from object at dir; action=append or kind name.

Example:

```
#run helper
#runwith 3 helper
#load n append
```

### Data

#### #array

**Args:** `name` val…

Set stat to array of values.

#### #read

**Args:** `from` `prop` `name`

Read from[prop] into stat.

Example:

```
#array dirs n e s w
#read self color mycolor
```

## Input Handling

`readinput` / `applyinputqueue` drains the player’s input queue each tick: coalesces all `MOVE_*` / `SHOOT_*` into `inputmove` / `inputshoot` (up to two dirs for diagonals, with FPV remap), and applies one button/action (`inputok`, `inputa`, sided ctrl, etc.).
